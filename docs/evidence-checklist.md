# Lista de evidencias académicas

Capture información sin mostrar tokens, contraseñas ni valores de Secrets.

- [ ] Workflow CI completo en verde.
- [ ] Pruebas xUnit ejecutadas y resumen TRX.
- [ ] Cobertura Cobertura descargable.
- [ ] Artefacto publicado descargable.
- [ ] Archivo y verificación SHA-256.
- [ ] Análisis CodeQL y alertas SAST.
- [ ] Dependency Review del PR o reporte NuGet vulnerable.
- [ ] Docker Build completado.
- [ ] Paquete `cga-app` publicado en GHCR.
- [ ] Tag ligado al commit.
- [ ] Digest inmutable de la imagen.
- [ ] Attestation de procedencia verificada.
- [ ] Reportes Trivy SARIF y tabla.
- [ ] Validación kubeconform de manifiestos.
- [ ] Reporte Trivy config.
- [ ] Pull Request de actualización GitOps.
- [ ] Argo CD en estado Healthy y Synced.
- [ ] Pods en estado Running/Ready.
- [ ] Aplicación abierta mediante el Service NodePort.
- [ ] Endpoint `/health` respondiendo 200.
- [ ] Smoke test completo.
- [ ] Reportes ZAP HTML y JSON.
